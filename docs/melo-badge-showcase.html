⭐ 推荐方案 A
月牙角标 🌙
在鱼 logo 右下角叠加紫色圆底 + 白色月牙图标，呼应「月颅」的月亮意象。
✓ 语义明确 ✓ 品牌统一 ✓ 辨识度高 △ 小尺寸需简化
方案 B
头型轮廓角标 📐
角标内显示简化的头型俯视轮廓 + 测量十字线，直观传达产品功能。
✓ 功能直观 ✓ 专业感强 △ 语义偏窄 △ 复杂度高
方案 C
渐变色 + 文字后缀 🎨
鱼身改为黄→紫渐变，底部加 "LUNA" 文字，不用角标纯色彩区分。
✓ 极简优雅 ✓ 缩放友好 △ 产品多时难扩展
⭐ 推荐方案 D
混合方案：微渐变 + 月牙角标 🌙🎨
鱼身嘴部微微渐变到淡紫暗示品类，同时右下角月牙角标强化识别。弹性最佳。
✓ 双重识别 ✓ 场景适应强 ✓ 品牌延展性好
